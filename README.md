# コヨーテゲーム

このリポジトリには、ブラウザでプレイできるシンプルなコヨーテゲームのウェブアプリケーションが含まれています。AIを相手に、数字を宣言したり、「コヨーテ！」と挑戦したりして、心理戦を楽しみましょう。

**実際にゲームをプレイする:** <https://onotaker.github.io/GoogleGemini-Coyote/>

## 概要

このコヨーテゲームは、シングルページアプリケーション（SPA）として実装されており、特別なインストールなしにブラウザで直接プレイできます。プレイヤーはAIと対戦し、各ラウンドで配られたカードの合計値を予測します。自分のカードは見えませんが、他のプレイヤーのカードは見えるため、それらをヒントに宣言をしたり、相手の宣言に挑戦したりします。
https://kurohyo0803.com/coyote/#index_id4

## 遊び方

1. `index.html` ファイルをブラウザで開きます。

2. ゲームが自動的に開始され、カードが配られます。

3. 画面下部の入力フィールドに数字を入力し、「宣言する」ボタンをクリックして宣言します。宣言する数字は、現在の宣言よりも大きい必要があります。

4. 相手の宣言が疑わしい場合は、「コヨーテ！」ボタンをクリックして挑戦します。

5. 挑戦が成功すれば相手のライフが減り、失敗すれば自分のライフが減ります。

6. ライフがすべてなくなったプレイヤーはゲームから脱落します。

7. 最後の1人になったプレイヤーが勝者となります。

## 主な機能

* **AI対戦**: 3人のAIプレイヤーと対戦できます。

* **シンプルなUI**: 直感的で分かりやすいインターフェース。

* **ライフシステム**: ライフが0になると脱落するシステム。

* **カード構成表示**: デッキに残っているカードの構成を視覚的に確認できます（AIのカードは表示されますが、自分のカードは隠されています）。

* **ゲームログ**: ゲームの進行状況や宣言の履歴をリアルタイムで確認できます。

## 使用技術

* **HTML5**: アプリケーションの構造。

* **CSS3 (Tailwind CSS)**: スタイリングとレスポンシブデザイン。

* **JavaScript (Vanilla JS)**: ゲームロジックとUIの動的な操作。
